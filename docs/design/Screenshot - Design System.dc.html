SCREENSHOT

Design system · v1.0

Un OS fictif conçu pour l'enquête. Trois idées : l'obscurité comme matière (des noirs étagés, jamais de dégradé), le blanc comme action (le seul élément plein est ce qu'on peut toucher en priorité), l'ambre comme signal (ce que le joueur a trouvé, ce qui presse). Le logo est un cadrage : le mot entre quatre repères de capture, le dernier en ambre.
