TRACEBUREAU DES ENQUÊTES

Charte visuelle · v2.0

Principe : de vieux dossiers criminels, présentés avec un design contemporain. Trois matières : le bureau (noir charbon, où tout est posé), le papier (dossiers, fiches, carnet : tout ce qui appartient à l'enquêteur), le verre (le téléphone saisi, réaliste). Le rouge est l'encre des tampons, jamais une couleur d'interface.

Construction : bordure 1.5–4 px + double filet intérieur (inset 2 px couleur du papier, puis inset 1–2 px rouge) + opacité .75–.9. Rotation fixe par type : −12° à +8°.
Encre : en production, appliquer un masque de grain (PNG 256², bruit d'encre) sur les tampons ≥ 22 pt pour un rendu irrégulier. Les petits tampons restent nets pour rester lisibles.
Qui tamponne : le jeu pose RÉSOLU, NON RÉSOLU, CONFIDENTIEL, SCELLÉ, NOUVEAU. Le joueur pose ÉLÉMENT CLÉ, ALIBI À VÉRIFIER, DISCULPÉ. Le jeu ne tamponne jamais une pièce à la place du joueur.

08

Icônes

Hors téléphone : trait 1.5 px, formes géométriques (Lucide recommandé), 20/24 pt, couleur de l'encre ou os. Aucune icône sur le papier, sauf ✕ ✓ + › dessinés en mono.
Téléphone : icônes d'OS réalistes, pleine couleur, dessinées pour TRACE (sans reprendre d'icônes Apple).
09

Style photo

Photographies réalistes, lumière de nuit : lampadaires sodium, néons, flash de téléphone. Désaturées de 30 %, noirs relevés (+6), grain fin. Pour les photos de pièces : cadrage « amateur » (léger flou de bougé, horizon penché) pour qu'on croie qu'elles viennent du téléphone. Pour les portraits de suspects : photo d'identité frontale, fond neutre gris, la même lumière pour les 4. Sur papier, toujours tirées (bord blanc) ; dans le téléphone, plein cadre.
10

Style document

En-tête : numéro de dossier (mono), titre (serif), éventuellement un tampon. Corps : grille de champs LIBELLÉ / VALEUR séparés par des filets. Prose en serif. Un document tient sur un seul écran quand c'est possible ; sinon « P. 1/2 » en haut à droite et défilement vertical de la feuille. Le texte est toujours droit, seuls les objets posés sur la feuille (photos, tampons, bordereaux) sont inclinés.
